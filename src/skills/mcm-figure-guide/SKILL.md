# 美赛论文图表专项指导

## 目标

每张图必须回答一个明确问题，并能在脱离正文时通过标题、坐标、图例和 caption 被正确理解。图表是美赛拿奖的关键——获奖论文图表占比通常高达 68%，纯文字论文很难获得高奖。

## 数据图 vs 非数据图（先分清，再动手）

| 类型 | 例子 | 由谁生成 | 工具 |
| --- | --- | --- | --- |
| 数据图 | 折线、柱状、散点、热力图、箱线、雷达、误差带 | 求解/分析阶段 | Matplotlib / Seaborn |
| 非数据图 | 技术路线图、求解流程图、模型结构图、指标体系图 | 独立绘制 | DrawIO / TikZ / networkx |

两者不能混用：流程图不能冒充数据图，数据图不能由 DrawIO 生成。

## 图类型选择（依据结论选图）

- 时间趋势 → 折线图 + 区间带
- 方案/类别比较 → 排序点图或条形图（避免饼图）
- 分布与风险 → 直方图 / 箱线图 / 小提琴图 / ECDF
- 变量关系 → 散点图 / 热力图
- 模型误差 → 预测-真实对比 / 残差图 / 校准图
- 不确定性 → 误差条 / 置信区间 / 情景带
- 敏感性 → 龙卷风图 / 响应曲线
- 多目标 → Pareto 散点 + 推荐解标注
- 空间结果 → 统一色标的分级图，注明投影与年份

## 非数据图选择

- 技术路线图：展示整体解题路线、章节逻辑
- 子问题求解流程图：单子问题输入/判断/算法/输出
- 数据处理流程图：清洗、特征构造、建模输入
- 模型结构图：模块关系、变量关系
- 指标体系图：目标层/准则层/指标层

## 论文规范（强制）

- PDF/SVG 矢量输出，禁止截图模糊。
- 轴名称包含变量和单位；图注说明样本、方法、区间含义、关键结论。
- 不在图内写大标题，标题交给论文 caption。
- 图文字与论文语言一致（美赛用英文）。
- 颜色在灰度打印下可区分，考虑色盲友好。
- 小数位与有效数字匹配数据精度。
- 避免伪 3D、彩虹色、截断坐标、双轴误导、重叠标签。

## Modulus 执行要求

用 `run_python` 执行 Matplotlib/Seaborn 脚本生成可复现图表；结果放入明确的图表目录，只汇报关键图表及其结论，不在进度区展示绘图代码。
