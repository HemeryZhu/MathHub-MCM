# 美赛真题题意解析

## 目标

把美赛真题转化为可执行的建模任务：先判断题型，再拆解子问题，最后给出模型选型建议。先完成问题定义，再选择模型。

## 美赛题型规律（A/B/C/D/E/F）

- **A 题（连续型）**：偏微分方程、物理/工程建模、优化；数学推导要求高。
- **B 题（离散型）**：图论、调度、组合优化、排队论；算法实现要求高。
- **C 题（数据洞察型）**：数据分析、机器学习、时序预测、可视化；数据处理能力要求高。
- **D/E/F 题（ICM 交叉学科）**：运筹学、可持续性、政策分析；跨学科和文字论证要求高。

## 工作流

1. 先判断题目属于哪个题型（连续 / 离散 / 数据洞察 / 交叉学科），据此确定主模型方向。
2. 阅读全部赛题与附件，核对 PDF 公式、上标下标、单位、表格字段，二次核对避免抽取错误导致模型方向偏差。
3. 只认题面明确编号的顶层问题（Problem 1/2/3）。不要把背景描述、数据说明、提交要求、小问编号或附件说明误当成独立子问题。
4. 对每个子问题说清：输入、输出、决策变量或预测对象、评价指标、约束条件，以及与前后子问题的递进或依赖关系。
5. 对题面模糊表述先列出两种以上解释，再用逻辑、简单验算或问题递进性判断采用哪一种。
6. 根据题型给出模型选型建议和"王炸组合"。

## 高频"王炸"组合

| 问题类型 | 推荐组合 |
| --- | --- |
| 综合评价 | AHP + TOPSIS 或 AHP + 熵权 + TOPSIS |
| 预测 + 不确定性 | XGBoost/随机森林 + Bootstrap 置信区间 |
| 风险评估 | Logistic 回归 + 蒙特卡洛模拟 |
| 时空预测 | ARIMA/LSTM + 空间聚类 |
| 投资/资源优化 | 预测模型 + 动态规划/遗传算法 |
| 状态建模 | 马尔可夫链/HMM + 随机森林验证 |
| 文本分析（C 题）| TF-IDF + LDA 主题模型 + 情感分析 |

## 输出结构

- 题型判定与理由
- 逐问需求矩阵（输入 / 输出 / 约束 / 评价指标）
- 已知量、未知量、决策变量
- 子问依赖关系
- 模型选型建议与王炸组合
- 可执行任务清单

## 质量规则

- 不把背景叙述误当成强制要求。
- 不遗漏单位、边界、时间尺度和最终交付格式。
- 不在问题尚未定义时直接跳到复杂算法。
- 每项结论都能追溯到题目原文或明确标注的假设。

## Modulus 执行要求

先用 `list_files` 和 `read_file` 获取赛题及附件；需要沉淀时用 `write_text_file` 生成简洁的问题规格文件。不要在进度面板粘贴赛题全文。
