# 美赛全流程编排

## 目标

把一道美赛真题从头到尾跑成一篇可提交的英文论文。先定义问题，再建模，再求解，再出图，最后写作与验收。每一步都有明确的产出文件和完成标准。

## 全流程链路

按顺序执行以下 8 个阶段，前一阶段完成并通过门禁后才进入下一阶段：

| 阶段 | Skill | 产出 | 门禁 |
| --- | --- | --- | --- |
| 1 题意解析 | `analyze-mcm-problem` | 问题规格（题型、子问题矩阵、王炸组合） | 题型判定明确、子问题无遗漏 |
| 2 数据理解 | `audit-modeling-data` + `explore-modeling-data` | 数据质量报告 + EDA 结论 | 缺失/异常/单位已核对 |
| 3 建模设计 | `mcm-modeling-guide` + `design-mathematical-model` | 变量/假设/目标函数/约束 | 公式可被代码实现 |
| 4 求解 | `mcm-modeling-guide` + `solve-optimization-model` / `forecast-time-series` / `simulate-uncertainty` | 数值结果 + 约束校验 | 约束回代通过、结果可复现 |
| 5 出图 | `visualize-model-results` + `mcm-figure-guide` | 数据图 + 技术路线图/流程图 | 每张图有依据、有 caption |
| 6 鲁棒性 | `validate-model-robustness` | 敏感性/误差分析 | 关键参数已扰动验证 |
| 7 论文 | `write-mcm-paper` | 英文论文 Word/PDF | 结构完整、数值一致 |
| 8 验收 | 自检清单 | 提交就绪检查 | 无占位符、图表引用完整 |

## 阶段边界

- 出图阶段只生成图表，不写论文正文；论文阶段引用图表，不重新生成图表。
- 数值必须能追溯到求解阶段的结果记录，论文阶段不得重新估算或换一套四舍五入口径。
- 每个阶段的结论都要能回到题面、数据或代码输出，不编造。

## 执行要求

- 先用 `list_files` / `read_file` 获取赛题与附件。
- 每完成一个阶段，用 `write_text_file` 沉淀该阶段的产出文件。
- 遇到歧义或数据不足，明确记录风险与替代方案，不编造数据字段和数值。
- 美赛论文强制英文，遵循 25 页限制与 AI 使用声明附录。

## 教练提示

全程可以随时询问：选型理由、某个模型的原理、图表为什么这样画、论文某段怎么写。Modulus 会根据当前阶段加载对应 Skill 回答。
